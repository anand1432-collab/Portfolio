# Anand Kanojia — Portfolio

A responsive, single-page portfolio with six browser-based interactive demonstrations.

## Run locally
Open `index.html` in a modern browser. For the best local development experience, use VS Code Live Server.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (keep `index.html` at the repository root).
3. In repository Settings → Pages, choose deployment from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish.

## Before publishing
- Replace the LinkedIn and GitHub placeholder URLs in `index.html`.
- Replace `your-email@example.com` with the email address you choose to publish.
- Review all content and confirm that no confidential company information is included.

## Demo limitations
All six demos are client-side simulations using fictional sample data. They do not connect to Google Sheets, Apps Script, n8n, company systems, email, or live business records. Changes made in a demo are temporary and are not saved to a server.

The portfolio uses a Google Fonts stylesheet from Google Fonts; the site remains readable with fallback fonts if the service is unavailable.
